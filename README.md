# Claude skills

Skills I have built for Claude, shared in case they are useful to someone else. Each folder is a complete skill with its own page, and each one installs on its own.

| Skill | What it does | Download |
| --- | --- | --- |
| [reader-annotations](reader-annotations/) | Turns a text or document into an HTML page you can highlight and annotate, in a Google Reader look. | [ZIP](https://github.com/torresburriel/claude-skills/raw/main/dist/reader-annotations.zip) |

## Install a skill

1. Download the ZIP of the skill you want from the table above. Do not unzip it.
2. In Claude, go to Customize > Skills.
3. Click the add button, choose "Upload a skill" and upload the ZIP.

In Claude Code, copy the skill's folder into `~/.claude/skills/`.

Every skill here is a text file of instructions. You can read all of it before installing, which is good practice with any third-party skill.
